# 北京顺义 → 大兴/亦庄搬家规划

这是一个面向家庭长期租住（计划 3 年以上）的公开决策项目。目标是在北汽蓝谷总部（北京经济技术开发区东环中路 5 号）周边，找到兼顾通勤、住房、停车、环境和幼儿园的稳定方案。

## 当前需求

> **完整、权威的选房标准（硬门槛、一票否决项、评分权重、通勤口径）统一在 [DECISION-MATRIX.md](DECISION-MATRIX.md)。** 本节只作概览，如有冲突以 DECISION-MATRIX.md 为准；修改标准也只改那一个文件。

概览：整租、建筑面积 ≥ 80㎡、月租 ≤ 5,000 元、**主力楼栋 2010 年后建成、70 年产权住宅**、平峰驾车到北汽蓝谷 ≤ 30 分钟（早高峰 40 分钟为绝对否决线）、有车需停车可落实、生活便利、幼儿园可进入且月均必要支出 ≤ 3,000 元。采育镇等远端片区作为"低租金换长通勤"的**远端权衡候选**单列，不因通勤直接淘汰。

- 候选池已从首轮 6 个片区扩展到全扇区（经开区核心 / 河西区 / 瀛海 / 旧宫 / 马驹桥 / 采育等），详见 [research/expanded-candidates.md](research/expanded-candidates.md)。
- 当前候选清单见 [DECISION-MATRIX.md 的「当前候选集」](DECISION-MATRIX.md) 与 [data/candidates.csv](data/candidates.csv)。

## 决策原则

先确认幼儿园可进入性和停车，再签租约。房租低但幼儿园无法稳定入读，或车位无法落实的房源，不进入最终候选。

所有房源价格和路线时间都是阶段性样本，不代表未来挂牌价、录取承诺或高峰通勤承诺。最终决定前必须完成工作日高峰试跑、幼儿园电话确认和夜间停车实测。
