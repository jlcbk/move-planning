# 幼儿园电话核验脚本

> 电话前先准备孩子的出生年月、计划入园时间、户籍类型、居住证情况和拟租小区名称。公开记录只写结论，不写个人信息。

1. 请问贵园是公办、普惠民办还是其他性质？当前保教费、伙食费和必须缴纳的代办费分别是多少？
2. 我们计划长期租住在「小区名」，该地址是否在贵园主要招生服务范围内？
3. 租房家庭可以报名吗？有北京户籍和非北京户籍时，材料和录取顺序分别是什么？
4. 是否要求房屋租赁备案？合同需提前多久生效？居住证或社保需连续多久？
5. 孩子拟于「年月」入小班/托班/插班，目前是否有名额或登记渠道？
6. 2026 或下一学年的信息采集平台、登记时间和通知渠道是什么？
7. 校车、延时托管、被褥、园服、兴趣活动是否自愿？月均必要总支出大约多少？
8. 如果本园未录取，通常由哪个部门协调，附近可替代的公立或普惠园有哪些？
