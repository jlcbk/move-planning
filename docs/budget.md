# 预算模型

## 月度上限建议

| 项目 | 目标值 |
|---|---:|
| 房租 | 5,000 元 |
| 幼儿园必要支出 | 3,000 元以内 |
| 车位 | 调研后填写 |
| 通勤新增成本 | 调研后填写 |
| 物业/能源/网络月均 | 调研后填写 |

幼儿园的 3,000 元口径应包含保教费、伙食费和必须缴纳的代办性费用；自愿兴趣班不纳入必要预算，但要单独列示。

## 一次性现金准备

- 押金与首期租金
- 中介费或平台服务费
- 搬家公司与打包材料
- 旧房退租重叠期
- 家具、电器和儿童安全改造
- 车位押金或充电设备
- 至少 15% 的应急缓冲

## 三年合同重点

- 第 2、3 年涨租幅度或固定价格
- 房东出售时继续履约的安排
- 家电、漏水、供暖等维修责任和时限
- 因幼儿园未录取而提前解约的协商条款
- 押金退还时间、扣款凭证和交接标准
- 房东配合租赁备案、居住登记和入园材料
